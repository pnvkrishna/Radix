# 1. AI Engineering

Large Language Models are trained on very large volumes of data and require large infrastructure.

Building an LLM is not practical for every organization.

This led to the concept of:

> **Model as a Service**

Organizations can use existing models and build AI-enabled applications around them.

```text
Foundation Model
      ↓
Model as a Service
      ↓
AI Application
      ↓
Business Problem
```

This reduced the barrier for enterprises to build AI-enabled applications.

---

# 2. Language Models

A language model works with:

* Tokens
* Vocabulary

A language model can perform tasks such as:

## Masked Language Model

The model predicts a missing token.

```text
Kids were ___ on the ground.
```

The model tries to fill the missing part.

### Simple idea

> **Fill in the blank.**

---

## Autoregressive Language Model

The model predicts the next token based on the previous context.

```text
Kids were screaming loud in the classroom
and then arrived the _____
```

### Simple idea

> **Predict the next token.**

---

## Difference

| Masked Language Model    | Autoregressive Language Model |
| ------------------------ | ----------------------------- |
| Predicts missing token   | Predicts next token           |
| Fill in the blank        | Continue the sequence         |
| Uses surrounding context | Uses previous context         |

---

# 3. Large Language Models

Language models trained on very large volumes of data and infrastructure are called:

> **Large Language Models (LLMs)**

LLMs can generate text.

At a basic level, an autoregressive LLM generates output by predicting tokens one after another until the generation stops.

```text
Input
 ↓
LLM
 ↓
Token
 ↓
Next Token
 ↓
Next Token
 ↓
...
 ↓
Response
```

# 7. RAG

RAG stands for:

> **Retrieval-Augmented Generation**

RAG is useful when the model needs relevant information from a specific knowledge source.

Examples:

* Chatbots
* Knowledge bases
* Private company information

Basic flow:

```text
User Question
      ↓
Retrieve Relevant Information
      ↓
LLM
      ↓
Answer
```

### Simple idea

> **RAG → Give the model relevant knowledge from an external knowledge source.**

# 8. AI Agents

AI Agents are useful when AI needs to:

> **Perform tasks and actions.**

An Agent is not just generating content. It can use a model, tools and a framework to reason and perform actions.

Basic idea:

```text
Goal
 ↓
Agent
 ↓
Reasoning
 ↓
Action
 ↓
Result
```

---

# 9. AI Agents vs Agentic AI

AI Agents and Agentic AI are related concepts.

## AI Agent

An AI Agent is an individual system that can perform tasks/actions using AI capabilities.

Examples:

* Customer service agent
* Hiring agent
* IT support agent
* Logistics agent

## Agentic AI

Agentic AI is the broader system/approach where AI works toward goals using reasoning, actions, tools and potentially multiple agents.

```text
Agentic AI
│
├── Single Agent
│
├── Multi-Agent
│
├── Tools
│
└── Workflows
```

### Simple difference

> **Agent → performs tasks/actions**

> **Agentic AI → broader goal-oriented AI system**

Agentic AI does not necessarily mean Multi-Agent.

# 10. What Makes an Agent Different?

A model can generate content such as:

* Text
* Code
* Images
* Music
* Video

But an Agent needs to go beyond content generation.

An Agent needs to:

```text
Reason
  ↓
Act
```

The key idea from the class is:

> **Agent = Reasoning + Actions**

# 11. Tool Calling

Models can be trained to help determine which tools should be called.

This ability is called:

> **Tool Calling**

For example:

```text
User
 ↓
"My product was not delivered"
 ↓
Model
 ↓
Select appropriate tool
 ↓
Tool Call
```

Tool calling allows the model to request the use of an available tool.

---

# 12. What is a Tool?

A simple definition from the class:

> **Tool: Does some action**

Examples:

```text
Read customer complaint
Read order information
Read shipping information
Read delivery information
Refund
Redeliver
Publish social-media content
```

Tools allow an Agent to interact with systems and perform actions.

---

# 13. Model vs Tool

Keep this distinction clear:

```text
Model
 ↓
Reason / decide what needs to happen

Tool
 ↓
Does the action
```

The model can determine which tool is required.

The actual tool performs the action.

# 19. Customer Complaint — Agent Example

A customer raises a complaint:

> "My product has not been delivered."

The customer-care representative needs information about:

* Order
* Shipping
* Delivery

Possible actions:

* Redeliver
* Refund

Required tools:

```text
Tool 1
Read customer complaint

Tool 2
Read order, shipping and delivery information

Tool 3
Refund / Redeliver
```

Possible workflow:

```text
Customer Complaint
       ↓
Read Complaint
       ↓
Read Order Information
       ↓
Read Shipping Information
       ↓
Read Delivery Information
       ↓
Decide Action
    ┌──┴──┐
    ↓     ↓
Refund  Redeliver
```

If the activity can be completed with simple approval from the customer-care representative, this can become an Agentic AI use case.

# 23. Basic Prompting

A good prompt can contain:

1. Role
2. Context / Level of understanding
3. Question
4. Constraints

Simple structure:

```text
Set Persona
     ↓
Set Context
     ↓
Ask
```

Example:

```text
You are an expert in stock market investing
and understand Indian stocks very well.

I want to understand Fundamental Analysis.

Apart from addition and calculating interest rates,
I don't know much about investing.

Give me a 10-day study plan with 30 minutes
of study time every day.

I understand concepts very well with analogies or stories.
```

The important idea:

> **Tell the AI who it should act as, explain your current level/context, clearly ask what you want, and provide constraints.**
